# SANTLADA — сайт натяжных потолков

Сайт мастера Исы Саидова (Хасавюрт, выезд по всему Дагестану). Клиент смотрит работы и фото «до / после», узнаёт цены на полотна (MSD Premium, BAUF, TEQTUM) и одной кнопкой пишет Исе в WhatsApp на **+7 928 598-34-32**, чтобы обсудить проект. Калькулятора нет — дизайн, профиль, свет и итоговую цену Иса обсуждает с клиентом сам. Сервер и база данных не нужны.

Сделано на [Astro](https://astro.build) + React + Tailwind CSS.

---

## Запуск на своём компьютере

Нужен [Node.js](https://nodejs.org) версии 22 или новее.

```bash
npm install        # один раз: установить зависимости
npm run dev        # открыть сайт: http://localhost:4321
```

Пока работает `npm run dev`, любые правки в файлах сразу видны в браузере.

## Как добавить работу

**Фото.** Положите файл (`.jpg`, `.png` или `.webp`) в папку нужного вида, например `src/assets/works/linii/`. Имя файла — латиницей или цифрами, без пробелов (удобно — номер поста в Telegram). Фото появится в галерее и в фильтре своего вида. Подпись по умолчанию — название вида. Свою подпись добавьте строкой в `src/data/works.ts`:

```ts
'931': { caption: 'Световые линии в гостиной' },
// показывать ещё и в фильтре «Парящие»:
'932': { caption: 'Линии и подсветка по периметру', also: ['paryashchiy'] },
```

Лучше держать в галерее 15–25 работ: самые удачные кадры разных видов, а не все подряд.

**Видео.** Сначала сожмите его — так оно будет быстро грузиться на телефоне (нужен [ffmpeg](https://ffmpeg.org)):

```bash
npm run compress-videos -- --type linii путь/к/видео.mp4
# можно ограничить длину и выбрать начало: --max 15 --start 3
```

Скрипт положит видео и обложку в `src/assets/videos/linii/`, и оно появится в галерее.

**«До / после».** Положите два фото одной комнаты в `src/assets/before-after/`: `<имя>-do.jpg` и `<имя>-posle.jpg`, и добавьте пару в список `beforeAfter` в `src/data/works.ts` (заголовок, короткий текст, вид потолка). Фото обрезаются до формата 4:5, поэтому главное должно быть в центре кадра.

**Удалить работу** — удалите файл из папки.

## Как улучшить качество фото

Фото из Telegram приходят размером 800 px и пережатыми. Перед добавлением на сайт их увеличивают в 4 раза нейросетью [Real-ESRGAN](https://github.com/xinntao/Real-ESRGAN) — линии и края становятся чёткими, пропадают «квадратики» сжатия.

1. Скачайте `realesrgan-ncnn-vulkan-…-windows.zip` со [страницы релизов](https://github.com/xinntao/Real-ESRGAN/releases) и распакуйте.
2. Увеличьте фото (на ноутбуке около минуты на кадр):
   ```bash
   realesrgan-ncnn-vulkan.exe -i исходное.jpg -o большое.png -n realesrgan-x4plus -t 64
   ```
3. Уменьшите результат до 1600 px по длинной стороне и сохраните в JPG (качество 88) — в любом редакторе, например в Paint («Изменить размер»).

Сайт сам сделает из него лёгкие WebP разных размеров.

## Новые фото и видео из Telegram-канала

```bash
npm run sync-telegram -- --from 930
```

Скрипт скачает посты канала начиная с №930 в папку `media-inbox/` (на сайт она не попадает): фото — в `photos/`, обложки видео — в `video-thumbs/`, список постов — в `manifest.json`. Номер поста — это число в ссылке `t.me/SantlaDAl/930`. Без `--from` скачаются все посты.

Сами видео скачиваются отдельно, по номерам постов:

```bash
npm run sync-telegram -- --videos 931,935
```

Через встроенный просмотр Telegram отдаёт фото максимум в 800 пикселей, а большие видео (длиннее ~40 секунд) не отдаёт совсем. Чтобы получить **оригинальное качество**, выгрузите канал через Telegram Desktop: «⋮ → Экспорт истории чата», отметить фото и видео. Получившиеся файлы кладите в папки так же — улучшать их уже не нужно.

## Как работают заявки

Все кнопки ведут в WhatsApp Исы с готовым текстом:

- **«Обсудить проект»** (нижняя панель на телефоне, блок «Проект») — просто начать разговор.
- **«Спросить про …»** в карточке полотна — сообщение с названием полотна.
- **«Хочу такой потолок»** у работы — сообщение со ссылкой на эту работу; ссылка откроет её на сайте на весь экран.
- **Форма замера** (блок «Контакты») — город, имя, удобное время, выбранное полотно и комментарий.

Клиент нажимает «Отправить» в своём WhatsApp и может сразу приложить фото понравившегося потолка. Номер для заявок задаётся в `src/config/site.ts` (`phoneDigits`).

## Публикация в интернете

Сайт статический: после `npm run build` достаточно загрузить содержимое папки `dist/` на любой хостинг.

Рекомендуем **российский хостинг** — Beget или Timeweb. С 2025 года зарубежные сервисы, например Cloudflare, в России иногда работают с перебоями.

1. **Домен.** Зарегистрируйте `santlada.ru` или другой свободный домен у регистратора (REG.RU, Beget, Timeweb). Стоит примерно 200–900 ₽ в год.
2. **Хостинг.** Подойдёт самый простой тариф для сайтов, а для начала — и бесплатный. Привяжите домен к хостингу: в панели хостинга «Сайты → Добавить домен».
3. **Адрес сайта в настройках.** Если домен не `santlada.ru`, замените адрес в трёх местах: `astro.config.mjs` (`site`), `src/config/site.ts` (`url`) и `public/robots.txt` (строка `Sitemap`).
4. **Сборка.** Выполните `npm run build`.
5. **Загрузка.** В файловом менеджере хостинга откройте папку сайта (обычно `public_html`) и загрузите туда **всё содержимое** папки `dist/`.
6. **HTTPS.** Включите бесплатный SSL-сертификат (Let's Encrypt) в панели хостинга.
7. После каждого изменения повторяйте шаги 4 и 5.

### Чтобы сайт находили в поиске

- Добавьте сайт в [Яндекс Вебмастер](https://webmaster.yandex.ru) и укажите карту сайта `https://ваш-домен/sitemap-index.xml`.
- Заведите карточку организации в Яндекс Картах и 2ГИС со ссылкой на сайт.
- Для статистики посещений создайте счётчик [Яндекс Метрики](https://metrika.yandex.ru) и впишите его номер в `src/config/site.ts` (`yandexMetrikaId`).

## Структура проекта

```
src/config/        настройки: site.ts (контакты и тексты), canvases.ts (полотна и цены)
src/data/works.ts  подписи к работам и пары «до / после»
src/assets/        фото полотен, работ, «до / после» и видео
src/components/    блоки страницы; works/ — галерея с просмотром на весь экран
src/lib/           тексты заявок (whatsapp.ts), сбор работ (works.ts), эффекты (fx.ts)
src/pages/         страницы: главная и 404
scripts/           скачивание из Telegram, сжатие видео, картинка для превью ссылки
public/            иконки, og.jpg, robots.txt
```

Картинка для превью ссылки в мессенджерах — `public/og.jpg`. Пересоздать её (например, после смены телефона): `python scripts/og-image.py` (нужен Python и `pip install pillow`).
